# 安全组配置错误告警处理方案

## 告警名称
- **告警名**: `SecurityGroupMisconfiguration`
- **告警级别**: 严重
- **触发条件**: 安全组拒绝流量比例超过 10%

## 问题描述
安全组配置错误会导致正常请求被拒绝，业务中断。

## 排查步骤

### 步骤1: 查看安全组规则
- 登录云控制台检查安全组入站/出站规则
- 确认是否有过于严格的规则

### 步骤2: 检查网络流量日志
**工具**: `query_logs`
**参数要求**:
- **地域**: `ap-guangzhou`
- **日志主题**: `vpc-flow-logs`
- **查询条件**: `REJECT`

### 步骤3: 测试端口连通性
```bash
telnet <ip> <port>
nc -vz <ip> <port>
常见原因分析
原因1: 规则顺序错误
特征:

拒绝规则在允许规则之前

处理方案:

调整规则顺序（允许优先）

删除不必要的拒绝规则

使用最小开放原则

原因2: 源 IP 限制过严
特征:

只允许特定 IP 访问

处理方案:

增加需要访问的 IP 段

使用安全组引用其他组

使用 VPC CIDR

原因3: 端口未开放
特征:

新服务端口未加入安全组

处理方案:

添加新服务端口

验证端口是否正确

紧急处理措施
临时放宽安全组规则（如 /0 临时开放）

使用堡垒机/跳板机

回滚安全组变更

验证步骤
确认业务流量正常通过

检查拒绝日志是否减少

验证安全合规性
