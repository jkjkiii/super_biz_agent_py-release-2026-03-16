# CDN 回源失败告警处理方案

## 告警名称
- **告警名**: `CDNOriginFailed`
- **告警级别**: 警告
- **触发条件**: 回源失败率超过 3% 持续 5 分钟

## 问题描述
CDN 回源失败会导致内容无法更新，静态资源访问异常。

## 排查步骤

### 步骤1: 查看 CDN 监控
- 登录 CDN 控制台查看回源失败率
- 按地域、运营商分析

### 步骤2: 检查源站健康
```bash
curl -I <origin_url>
步骤3: 查看源站日志
工具: query_logs
参数要求:

地域: ap-guangzhou

日志主题: nginx-access-logs

查询条件: status:5xx

常见原因分析
原因1: 源站不可用
特征:

源站 5xx 错误或超时

处理方案:

重启源站服务

切换备用源站

检查源站资源使用

原因2: CDN 配置错误
特征:

回源域名解析失败

回源端口错误

处理方案:

检查回源配置

验证回源域名解析

测试回源连接

原因3: 网络波动
特征:

特定地区回源失败率高

处理方案:

检查源站防火墙和安全组

使用智能 DNS

增加多源站

紧急处理措施
手动刷新 CDN 缓存

将流量切到备用源站

临时增加源站带宽

验证步骤
确认回源成功率恢复（>99%）

测试静态资源访问

监控 CDN 缓存命中率
